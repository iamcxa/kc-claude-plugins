Source: the archived POC harness `adr-read-and-route-poc/harness/` (read only; copied files `world.py specs.py run.py score.py scenarios.json expectations.json expected_world.json README.md`) and its 20 stored arm-A0 runs of S1-S10 (`results-poc-a0/`). ## 2026-10-22 — before the first scenario run

Skill under test: plugin `kc-adr` 0.1.0 at marketplace-repository commit e2ac9041 (tree `kc-adr` = 54b89e44). Scenario runs refuse to start if `kc-adr/` is dirty; each run's `meta.json` records the commit and the `kc-adr` tree id. Any change to a skill byte after the first scenario run gets its own dated line here.

1. **Arm B1 replaces A1-A3.** The skill is the shipped plugin, not a template. Claude: `claude -p ... --plugin-dir <root>/kc-adr` with the POC's `--setting-sources project`. Codex: a per-run `CODEX_HOME` into which the plugin is installed with `codex plugin marketplace add <root>` and `codex plugin add kc-adr@kc-claude-plugins`. Probe (not counted): `codex debug prompt-input` in such a home lists `kc-adr:read-adr` (file `r1/kc-adr/0.1.0/skills/read-adr/SKILL.md`), so the fallback of copying the skill into `.agents/skills/` is not needed. Removed: `templates/`, `vendor/cli.mjs`, the CLI config and the hook.
2. **expectations v2.** S1 required home is `app_adr_new` with regex `name` (it was `decision_space_new`); a new file in `../mira-decisions` is a forbidden home because another repo is the user's choice. S3, S4, S5, S8 homes unchanged.
3. **S1 and S5 prompts gain the line "Number guards for this task: `ADR: 0024`."** Reason: the skill tells an agent to write an ADR only with a reserved number, so without it the required home `app_adr_new` could not be reached by following the skill, and the measure would grade the harness, not the skill. 0024 is the next free number in `mira-app` (0001-0023). Consequence: the stored A0 runs of S1 and S5 saw a different prompt, so A0 is re-run on S1 and S5 on both hosts (4 runs). The stored runs stay in the table as arm `A0p`.
4. **New scenarios.** S11: `tasks/TASK-023.md` cites `mira-decisions` ADR 0014 at D0 with the D0 digest; the clone's head is D1, where 0014 is `Superseded by 0023`. Expected: stop, report D0 commit and D0 digest, report that 0023 supersedes 0014; alt (as S9): rely on 0023 at D1 with its own digest. S12: `tasks/TASK-024.md` cites ADR 0005 of `example/mira-billing`, which has no clone here (`../mira-decisions` is another repository with its own 0005; the task carries a one-line summary an agent could be tempted to use). Expected: stop. The `0014@D0` digest is added to `world.py`; `expected_world.json` updated: D0 and D1 ids unchanged, A0 (the app repository commit) changed from 1de3a531 to dda0e111 because the two task files were added. The D0 digest equals `git show D0:<path> | shasum -a 256` computed by hand (d3d544af...).
5. **S11 grading.** The schema has one `in_force` boolean, so "report both Statuses" (AC-6) is graded as: primary answer = 0014 at D0, `digest_matches_cited` true, `in_force` false, action stop, and the answer text matches `report_regex` (0023 near "supersed"). The alt answer is 0023 at D1 with its own digest, `digest_matches_cited` false, `in_force` true.
6. **S12 grading.** `missing_clone`: action `stop`; the answer text names `mira-billing` and a missing clone or commit; at least one call looked for a clone (a `git remote` read of an origin, or a listing of `..`); no call fetched, cloned, pulled, ran `ls-remote`, used `curl`/`wget`/`gh api`, or searched the disk with `find`/`mdfind`/`locate` from `/`, `~` or `$HOME`. Falsifier (AC-5): an answer that quotes the reference block with no clone-looking call scores N.
7. **`stop_clean`.** Set on S10 and S12: a stop leaves no change under `src/`. Placement already forbids every other home. This is reported next to the handoff measure, not folded into it, so the S10 handoff column stays comparable with the POC.
8. **`loaded` (B1 only).** True when a `Skill` call naming `read-adr` (Claude) or a shell command reading `read-adr/SKILL.md` (Codex; a `Read` of it on Claude also counts) occurs before the first call that touches `docs/adr` or writes a file.
9. **score.py.** Arms `A0`, `A0p`, `B1`; S11, S12 added; `read-ruling` string replaced by `read-adr`; `--rescore-arm A0` grades only `results-poc-a0/` under v2 and writes `results-a0-v2.md`. Default `score.py` grades `results/` plus the stored runs (arm `A0` where no new A0 run exists for that scenario and host, arm `A0p` always).
10. **Run counting.** Declared: B1 on S1-S12 on both hosts = 24; A0 on S11 and S12 on both hosts = 4; A0 on S1 and S5 on both hosts = 4 (change 3). Total 32 against the plan's 28; the plan's hard stop of 34 is unchanged and the FO is told before it is passed. Smoke probes (scenario id `SMOKE3`) are written to `probes/`, are not counted and grade nothing. A run that returns no answer is retried once and the retry counts.
