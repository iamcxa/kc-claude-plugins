# Connect a project to its ops inbox (runbook, r1)

Project <project> = spacedock-dev/subspace-relay · trigger repository <trigger> = spacedock-dev/subspace-relay-ops-trigger · inbox <inbox> = https://subspace-relay-ops-inbox.netlify.app/inbox
Run the steps in order. "Captain only" steps touch an App, a key, a secret, a webhook or a ruleset; nobody else runs them.
Each step names the read-back rows (R1 to R15) that prove it; S11 runs them all.

## S1 · agent may run · Create <trigger>, private, holding only ops-event.yml

    gh repo create spacedock-dev/subspace-relay-ops-trigger --private --add-readme
    gh api -X PUT repos/spacedock-dev/subspace-relay-ops-trigger/contents/.github/workflows/ops-event.yml -f message="add ops-event" -f content="$(base64 < kc-ops-inbox/trigger/ops-event.yml)"

Read back by: R1 R2

## S2 · Captain only · Register the dispatch App (Actions write) and install it on <trigger> only

    open "https://github.com/settings/apps/new?name=relay-ops-dispatch&public=false&webhook_active=false&url=https://github.com/spacedock-dev/subspace-relay&actions=write"
    then Install App > Only select repositories > spacedock-dev/subspace-relay-ops-trigger; note the App ID and installation ID

Read back by: R6 R7

## S3 · Captain only · Register the agent App (contents, pull requests write) and install it on <project> only

    open "https://github.com/settings/apps/new?name=relay-ops-agent&public=false&webhook_active=false&url=https://github.com/spacedock-dev/subspace-relay&contents=write&pull_requests=write"
    then Install App > Only select repositories > spacedock-dev/subspace-relay; note the Client ID

Read back by: R8

## S4 · Captain only · Store the two App keys, then delete the downloaded files

    netlify env:set DISPATCH_APP_PRIVATE_KEY --secret --site subspace-relay-ops-inbox "$(cat ~/Downloads/relay-ops-dispatch.*.private-key.pem)"
    gh secret set OPS_AGENT_APP_PRIVATE_KEY -R spacedock-dev/subspace-relay-ops-trigger < ~/Downloads/relay-ops-agent.*.private-key.pem

Read back by: R9

## S5 · Captain only · Create the signing secret; store it in the inbox and in relay's deploy; store the model token

    node kc-ops-inbox/bin/secret-new.mjs | tee >(netlify env:set WEBHOOK_SECRET --secret --site subspace-relay-ops-inbox) | netlify env:set RELAY_OPS_INBOX_SECRET --secret --site <relay site> --context deploy-preview
    claude setup-token, then: gh secret set CLAUDE_CODE_OAUTH_TOKEN -R spacedock-dev/subspace-relay-ops-trigger

Read back by: R10 R11

## S6 · Captain only · Create a Slack incoming webhook for one channel and store its URL

    netlify env:set SLACK_WEBHOOK_URL --secret --site subspace-relay-ops-inbox   (paste the URL when asked)

Read back by: R12 R13

## S7 · agent may run · Deploy the inbox and set its non-secret settings and <trigger>'s variables (needs S2's and S3's ids)

    netlify sites:create --name subspace-relay-ops-inbox && netlify deploy --prod --site subspace-relay-ops-inbox --dir kc-ops-inbox/site --functions kc-ops-inbox/site/functions
    netlify env:set OPS_TRIGGER_REPO spacedock-dev/subspace-relay-ops-trigger --site subspace-relay-ops-inbox   (also OPS_WORKFLOW, DISPATCH_APP_ID, DISPATCH_INSTALLATION_ID)
    gh variable set OPS_PROJECT_REPO -R spacedock-dev/subspace-relay-ops-trigger --body spacedock-dev/subspace-relay; gh variable set OPS_AGENT_APP_CLIENT_ID -R spacedock-dev/subspace-relay-ops-trigger --body <S3 Client ID>

Read back by: R3 R4

## S8 · agent may run · Create spacedock-state/ops in <project> and open the setup Draft PR (ops-gate.yml, docs/ops/README.md)

    gh api -X POST repos/spacedock-dev/subspace-relay/git/refs -f ref=refs/heads/spacedock-state/ops -f sha=<root commit printed by kc-ops-inbox/bin/state-root.mjs>
    gh pr create -R spacedock-dev/subspace-relay --draft --head ops-inbox-setup --title "chore(ops): connect the ops inbox" --body-file kc-ops-inbox/setup/setup-pr.md

Read back by: R5

## S9 · Captain only · Apply the five rulesets; agent-creations lets only the repository admin role and the listed release bot create branches outside ops/** and spacedock-state/ops, the other four have an empty bypass list

    for f in main ops-branches state-branch agent-creations; do gh api -X POST repos/spacedock-dev/subspace-relay/rulesets --input kc-ops-inbox/setup/ruleset-$f.json; done
    gh api -X POST repos/spacedock-dev/subspace-relay-ops-trigger/rulesets --input kc-ops-inbox/setup/ruleset-trigger-main.json

Read back by: R14

## S10 · Captain only · Review and merge the setup PR, so ops-gate.yml is on the default branch

    gh pr view ops-inbox-setup -R spacedock-dev/subspace-relay --web

Read back by: R15
