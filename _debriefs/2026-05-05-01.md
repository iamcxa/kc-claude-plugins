## Decisions

- **Option A retrofit (vs Option B silent decision) at the non-UI design gap moment.** Maximizes evidence value for ship-flow maintainer over single-pitch time savings. Trade ~15-20 min retrofit cost for the audit trail in `todos/ship-flow-non-ui-design-routing-gap.md`.
- **Cand 1 → Cand 2 course correction after PR #8 Copilot review.** Cand 1 (`find role <r> --name "<v>"` subcommand strings stored as `selector:` values) was structurally wrong — agent-browser parses `find` as a verb-prefix subcommand family, not a selector grammar. Cand 2 (CSS attr form `[role="X"][aria-label="Y"]`) was originally rejected for RNW edge cases but works as a valid selector string. RNW gap downgraded from blocker to soft-limitation rabbit-hole.
- **Option 2 verify deferral (vs Option 1 live runtime DCs).** Captain Bet observation window IS the level-C runtime gate by design; running live `/e2e-map` → `/e2e-test` against jaffle-shop-golden requires Snowflake env vars not in this session. Linter (DC-1.3) provides continuous regression protection between merge and ship+1w retro.
- **PR-review-as-runtime-DC equivalence.** When verify-stage runtime DCs are deferred to post-merge bet observation, external static-contract review (Copilot, manual reviewer) can supply equivalent gating evidence pre-merge. Captain Bet condition (1) — "find role subcommand sufficiency" — was caught by Copilot's static analysis exactly as the bet would have caught it post-merge. Worth pinning as a fallback gate for plugin-internal pitches lacking a project dev server.
- **Path C in-PR fixup (vs Path A close+reshape) for the Cand 1 → Cand 2 flip.** 3 fixup commits + 1 round-2 commit landed on the same PR branch instead of opening a new pitch. Preserves the audit trail and demonstrates self-correction loop.

Cherry-picked only the pitch 001 commits onto a clean branch from origin/main (Option A); kc-hyperfocus opened as separate PR #9; pr-merge mod opened as PR #10.
