## Issues — Workflow

- **The harness's first pass through a merge gate found a defect in the harness.** `--arms` was read
  as first-name-and-last-name, so on the pre-registered directory that holds `A`, `A'` and `B`
  together, `--arms A,A_prime,B` dropped the middle arm and returned a real, plausible A-vs-B
  verdict for a comparison nobody asked for — a silently wrong acceptance verdict. The park meant it
  had never faced a merge gate, so the defect stayed hidden. Fixed in `e2ebda9`; reverting the guard
  fails exactly the two new assertions and nothing else.
- **The span table binds the live tree.** Merged PR #82 deleted `S8`, taking the harness from 80/80
  to 50/80. Failing closed is the intended behavior, but the cost is a re-derivation every time
  enumerated prose moves.
- **`review-post.test.sh` is not safe to run concurrently.** Two overlapping runs collide on shared
  payload state (`unsettled prior attempt exists for this payload`), so the first result was not
  trustworthy and needed an isolated rerun.
- **Product/sprint migration is still not done.** This session annotated one entity. Until every
  non-archived entity is backfilled, product and sprint filters are not authoritative.
