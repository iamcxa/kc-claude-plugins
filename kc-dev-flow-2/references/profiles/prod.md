# Production: operated capability

Deliver an operated capability with explicit long-term ownership.
Select applicable compatibility, lifecycle, migration/recovery, observability,
integrity, rollback, release, security and privacy obligations from the actual
boundary rather than adding every possible check.

Prefer existing repository and platform mechanisms. A new operational surface
needs an owner and failure policy. Use deterministic checks for decidable claims
and specialist assurance when evidence or risk warrants it.
Bind validation and delivery evidence to the exact revision; the user or named
release owner retains release authority.

Approved recovery exceptions must retain their bounded scope, evidence and
authorization; this scaffold does not implement the former loader's eligibility
checks. Unresolved eligibility returns to FO rather than silently skipping work.
