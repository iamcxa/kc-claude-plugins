# v2.0 Roadmap Archive — Parallel Execution + Auto-Action

**Shipped:** 2026-03-23
**Duration:** 3 days (2026-03-21 → 2026-03-23)
**Scope:** 4 phases, 9 plans, 17 requirements, 60 commits, +2754/-351 LOC

## Milestone Goal

Enable parallel target execution with per-target scheduling, auto-create PRs and Linear issues from run results, and surface outcomes in a dedicated page and NW-Claude chat.

## Key Accomplishments

1. **Parallel target execution** — Different targets run concurrently, same-target queues. Per-target Map isolation + cancel scoping
2. **Per-target scheduling** — Independent timers per target, custom interval override, 10-min minimum enforcement
3. **Auto-action pipeline** — Worker auto-creates PRs (gh) and Linear issues after runs. Dedup prevents duplicates
4. **Outcomes page** — Dedicated page for all NW-created PRs/issues, filterable by target/type/status
5. **NW-Claude outcome queries** — 3 MCP tools let chat answer "what PRs did NW create this week?"
6. **Dashboard UX polish** — 5-tab nav, parallel status dots, schedule display, wizard schedule step, nav gap fix
