    **Step 2: Create `app/worker/worktree-manager.ts`**

    Create the module with these exact exports (per Research.md architecture patterns):

    1. `runGit(cwd: string, args: string[]): Promise<{ exitCode: number; stdout: string; stderr: string }>` — Bun.spawn(['git', ...args]) wrapper, piping stdout/stderr to strings via `new Response(proc.stdout).text()`. Consistent with existing Bun.spawn pattern in executor.ts.

    2. `ensureWorktreesExcluded(repoPath: string): Promise<void>` — Per D-03. Read `.git/info/exclude` via `fs.readFile` (catch ENOENT, default to empty string). If content does not include `.worktrees`, append `\n.worktrees\n`. MUST be called BEFORE first `git worktree add`.

    3. `detectDefaultBranch(repoPath: string, configBranch?: string): Promise<string>` — Per D-06. Chain: (1) return `configBranch` if truthy, (2) `git symbolic-ref refs/remotes/origin/HEAD` — if exitCode 0, extract branch name by replacing `refs/remotes/origin/` prefix, (3) `git rev-parse --verify origin/main` — if exitCode 0 return `'main'`, (4) `git rev-parse --verify origin/master` — if exitCode 0 return `'master'`, (5) throw `new Error(\`Cannot detect default branch for \${repoPath} — set target.default_branch in nightwatch-targets.yaml\`)` per D-07.

    4. `createWorktree(repoPath: string, worktreePath: string, branch: string): Promise<void>` — Per D-08/D-09/D-14. Call `ensureWorktreesExcluded(repoPath)` first (D-03 ordering). Then `runGit(repoPath, ['worktree', 'add', '--detach', worktreePath, \`origin/\${branch}\`])`. If exitCode !== 0: `runGit(repoPath, ['worktree', 'prune'])` then retry. If retry exitCode !== 0: `throw new Error(\`worktree_creation_failed: \${retry.stderr.trim()}\`)` per D-09.

    5. `detectWorktreeBranch(repoPath: string, worktreePath: string): Promise<string | null>` — Per D-12. `runGit(repoPath, ['worktree', 'list', '--porcelain'])`. Parse output: split on `\n\n` to get blocks, find block where first line is `worktree ${worktreePath}`, look for line starting with `branch ` — if found return after stripping `branch refs/heads/` prefix, else return null (detached).

    6. `cleanupWorktree(repoPath: string, worktreePath: string): Promise<void>` — Per D-12. Call `detectWorktreeBranch`. If branch exists: `runGit(worktreePath, ['push', 'origin', branch])` (cwd is worktreePath for push). Then always: `runGit(repoPath, ['worktree', 'remove', '--force', worktreePath])`. Use `--force` because Claude's run leaves untracked files (Research pitfall #2).

    All functions use `import path from 'node:path'`, `import fs from 'node:fs/promises'`. No external dependencies.
