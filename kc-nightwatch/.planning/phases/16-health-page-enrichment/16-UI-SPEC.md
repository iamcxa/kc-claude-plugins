## Spacing Scale

Declared values (multiples of 4). Derived from measurement of existing component inline styles.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Padding: `<td>` cell top/bottom, indicator row vertical padding |
| sm | 8px | Card internal padding (compact rows), section label margin-bottom, table cell top/bottom padding |
| md | 12px | Card padding (primary), indicator row gap, table cell horizontal padding |
| lg | 16px | Page horizontal margin (all cards), section margin-bottom, page padding |
| xl | 24px | Not used in Phase 16 |
| 2xl | 32px | Not used in Phase 16 |
| 3xl | 64px | Not used in Phase 16 |

Exceptions:
- Sparkline hit rect: full-height (20px default = sparkline height), no minimum. Column width = `pointSpacing` (derived from data count).
- ForgeResultCard collapsed height: matches existing target card header line (approximately 40px) — same as HealthSummaryBar height.
- Tooltip div: fixed height 36px above sparkline container (`top:-36px`), 4px 8px padding.
- Table cell padding: `padding: 8px 12px` (8px top/bottom, 12px left/right) — multiples of 4 on both axes.

## Typography

All sizes derived from existing codebase measurements. No external font loading.

Scale reduced from 4 to 3 sizes: 13px secondary label consolidated into 14px body to eliminate the 1px step between 13px and 14px. 12px section subheadings standardized to 11px to keep the scale at 3 sizes.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Page heading | 16px | 600 (semibold) | 1.2 | "Flywheel Health" page title, target name |
| Body / label | 14px | 400 (regular) for labels, 600 (semibold) for values | 1.5 | Indicator name, ForgeResultCard text, table cell text, button text, indicator current value (numeric), runs analyzed count, ForgeResultCard branch + details text |
| Micro / caption | 11px | 400 (regular) | 1.4 | Tooltip content, section subheadings, CalibrationTable header row, chart axis labels, Sparkline fallback "--" |

Font weights in use: **400** (regular) and **600** (semibold) only.

## Component Inventory

New components to create in `app/frontend/components/`:

### 1. `forge-result-card.ts` (NEW)

**Collapsed state (default):**
```
[status-icon] [pass|fail badge] [relative time]   [▸ expand chevron]
```
- Container: `background:var(--panel);border:1px solid var(--border);border-radius:6px;padding:12px;margin:0 16px 16px;cursor:pointer;`
- Status icon: Unicode — ✓ for pass, ✗ for fail, — for null/stale
- Badge: inline colored text using `var(--success)` / `var(--error)` / `var(--muted)`
- Relative time: "Xh ago" / "Xd ago" / "just now" / "never" — `font-size:14px;color:var(--muted)`
- Expand toggle: `useState<boolean>(false)`, click anywhere on collapsed row

**Expanded state (below collapsed row):**
```
Branch: kc-nightwatch/2026-03-26-e2e-pipeline-forge-fix
Details:
  • [detail item 1]
  • [detail item 2]
```
- Expanded section: `padding-top:8px;border-top:1px solid var(--border);margin-top:8px;`
- Branch line: `font-size:14px;color:var(--text);font-family:var(--font-mono);`
- Details list: `<ul>` with `font-size:14px;color:var(--muted);margin:4px 0;padding-left:16px;`
- Expand/collapse: instant toggle (no CSS transition) — consistent with utilitarian aesthetic

**Null / no-data state (forge_result === null):**
- Collapsed row shows: "— No forge run recorded" in `var(--muted)` color
- No expand behavior (nothing to expand)

**Stale state (data.stale === true):**
- All text color: `var(--muted)` — entire card grayed
- Relative time shows age ("3d ago") to signal staleness

**Keyboard / accessibility:**
- `role="button"` and `tabIndex={0}` on clickable collapsed row
- `aria-expanded={expanded}` on container
- `onKeyDown` handler: Enter and Space keys toggle expand

### 2. `calibration-table.ts` (NEW)

**Structure:**
```
[Section header: "Calibration"] (11px, semibold, var(--muted))
<table>
  <thead>
    Indicator | Threshold | Reject % | Feedback Count
  </thead>
  <tbody>
    [row per indicator, sorted by reject_rate descending]
  </tbody>
</table>
```

- Table container: `width:100%;border-collapse:collapse;font-size:14px;`
- Container wrapper: `background:var(--panel);border:1px solid var(--border);border-radius:6px;padding:12px;margin:0 16px 16px;`
- Header row: `font-size:11px;font-weight:600;color:var(--muted);text-align:left;padding:8px 12px;border-bottom:1px solid var(--border);`
- Data row: `font-size:14px;color:var(--text);padding:8px 12px;border-bottom:1px solid var(--border);`
- Last row: no bottom border

**Threshold cell (N-gate):**
- When `current_threshold === null`: render `threshold_null_reason` string — `font-style:italic;color:var(--muted);`
- When `current_threshold !== null`: render `${Math.round(current_threshold * 100)}%` — `color:var(--text);`
- Source field: `threshold_null_reason` from backend (do NOT hardcode "(N/10)" in frontend)

**Props:**
```typescript
interface CalibrationTableProps {
  calibration: CalibrationData[] | null  // null = loading; [] = empty after fetch
  loading: boolean
}
```

**Loading state:** Single row spanning all columns: "Loading..." in `var(--muted)`
**Empty state:** Single row spanning all columns: "No feedback collected yet — run the pipeline to generate data." in `var(--muted)` — appears only when `calibration` is `[]` (not null)

### 3. Sparkline tooltip enhancement (MODIFY `sparkline.ts`)

**New props:**
```typescript
interface Props {
  values: number[]
  width?: number
  height?: number
  runIds?: string[]  // parallel to values; optional — tooltip degrades to value-only when absent
}
```

**Container change:**
- Wrap `<svg>` in `<div style="position:relative;display:inline-block;">` to scope absolute tooltip positioning

**Hit area rects (inside SVG, after polyline):**
- One `<rect>` per data point
- `fill="transparent"`, `cursor="default"`
- Full SVG height, centered on x coordinate
- Edge guards: first point rect starts at x=0; last point rect ends at x=width
- `onMouseEnter={() => setActiveIdx(i)}`, `onMouseLeave={() => setActiveIdx(null)}`
- `pointer-events` on `<polyline>`: set to `none` so rect captures all events

**Tooltip div (sibling to SVG, OUTSIDE it, inside container div):**
- `position:absolute;top:-36px;pointer-events:none;z-index:10;`
- `background:var(--panel);border:1px solid var(--border);border-radius:4px;padding:4px 8px;`
- `font-size:11px;color:var(--text);white-space:nowrap;`
- Horizontal position: `left:${x}px;transform:translateX(-50%)` for middle points
- Edge guard: first point → `left:0;transform:none`; last point → `right:0;left:auto;transform:none`
- Line 1: `${Math.round(values[activeIdx] * 100)}%` (value as percentage)
- Line 2 (when runIds present): run ID in `var(--muted)` color at `font-size:11px`
- When `runIds` absent: show value only (single line)

**State:** `const [activeIdx, setActiveIdx] = useState<number | null>(null)` — local to component

## Page Layout Contract

Source: CONTEXT.md D-01, D-02

**Primary visual anchor:** ForgeResultCard — positioned immediately below HealthSummaryBar.

**Section order (top to bottom):**
1. Page heading ("Flywheel Health") — existing, unchanged
2. `HealthSummaryBar` — existing, unchanged
3. Loading / error / sparse-data notice banners — existing pattern, unchanged
4. **`ForgeResultCard`** — NEW, inserted between HealthSummaryBar and Target Cards
5. Target Cards (per-target health + sparklines) — existing, enhanced with tooltip
6. **`CalibrationTable`** — NEW, inserted between Target Cards and Reject Rate Charts
7. Reject Rate Charts section — existing, unchanged

**Layout model:** Single scrollable column. No tabs, no grid, no sidebar. All sections share the same `margin:0 16px 16px` horizontal spacing. Source: CONTEXT.md D-02.

**Section dividers:** No `<hr>` elements. Sections are visually separated by the card backgrounds (`var(--panel)`) against the page background (`var(--bg)`). Section subheadings use `font-size:11px;font-weight:600;color:var(--muted);margin-bottom:8px;` (existing pattern from Reject Rate Charts section, standardized to 11px).
