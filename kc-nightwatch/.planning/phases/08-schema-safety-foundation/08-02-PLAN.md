<objective>
Wire the new IPC state shape (active array instead of single current) through all consumers: worker state broadcasting, server IPC handler, and frontend API client. Update the cancel handler to use Map-based PID lookup.

Purpose: Without this wiring, the server and frontend would still expect the old `current?: Run` shape and break when receiving `active: Run[]` from the worker. The cancel handler must also be updated to use the new Map-based activePids.

Output: Worker, server, and frontend all speak the same `active: Run[]` state shape. Cancel targets a specific run. All IPC and queue tests pass.
</objective>
