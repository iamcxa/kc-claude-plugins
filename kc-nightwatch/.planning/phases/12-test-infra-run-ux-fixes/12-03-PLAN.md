  In `app/server/routes/config.ts`:

  1. Add import at the top:
     ```typescript

     ```

  2. In `POST /api/config/targets/add` (after the name check on line 65, before `withWriteLock`):
     ```typescript
     const targetPath = (target as Record<string, unknown>).path as string | undefined

       return c.json({ error: `path does not exist: ${targetPath}` }, 400)
     }
     ```
     Use `existsSync` (not `Bun.file().exists()`) because target paths are directories, not files. `existsSync` works for both files and directories.

  3. In `PUT /api/config/targets/:name` (after line 86 `const { target } = ...`, before `withWriteLock`):

     ```typescript
         return c.json({ error: 'path is required' }, 400)
       }
       if (!existsSync(targetPath)) {
         return c.json({ error: `path does not exist: ${targetPath}` }, 400)
       }
     }
     ```
     Note: In edit mode, path may not be included in the payload (if the user didn't change it). Only validate when path is explicitly provided. But if provided, it must be non-empty and exist on disk.
