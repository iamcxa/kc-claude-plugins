# Production Base

## Outcome

Deliver an operated capability with explicit long-term ownership.

## Working rules

- Define applicable compatibility, lifecycle, migration/recovery,
  observability, integrity, rollback, release, security, privacy, and ownership
  obligations from the actual boundary.
- Prefer existing platform and repository mechanisms; every new operational
  surface needs an owner and failure policy.
- Use deterministic gates for decidable claims. Select specialist review only
  for the risks the change actually carries.
- Use Chief Engineer advice for delivery sequencing or blockers. Use Science
  Officer assurance for contested, high-risk, hard-to-reverse, or low-confidence
  technical calls; neither is a universal gatekeeper.
- Bind validation and delivery to the exact revision. Captain or the declared
  release owner retains release authority.
