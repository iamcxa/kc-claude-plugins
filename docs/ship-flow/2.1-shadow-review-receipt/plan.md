# Shadow Review Receipt Implementation Plan

> **For executer:** REQUIRED SUB-SKILL: use `superpowers:executing-plans` task-by-task and preserve the Ship-Flow TDD ledger.

**Goal:** Add a local exact-head shadow receipt and deterministic paired-run baseline without changing review, confirmation, or GitHub behavior.
**Architecture:** A source-safe Bash library owns typed JSONL validation, append, replay, and inspection; the review skill calls one best-effort observer after the final draft/event is known but before confirmation. A separate deterministic benchmark compares sanitized receipts and never dispatches an LLM.
**Tech stack:** Bash 3.2+, `jq`, Git/GitHub evidence pointers, JSONL, plain-Bash tests, GitHub Actions.
